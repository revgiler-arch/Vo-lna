# Волна — музыка с YouTube Music без рекламы

Личный аудиоплеер для Android: поиск песен YouTube Music, фоновое воспроизведение,
бесконечное радио, без рекламы, без Shorts, без аккаунта. История, лайки и лента
«Для вас» хранятся только на телефоне.

## Как получить APK

### Вариант 1. GitHub Actions (без Android Studio)
1. Создайте **приватный** репозиторий на GitHub и загрузите туда содержимое этой папки
   (через сайт: Add file → Upload files, перетащить всё, включая скрытую папку `.github`).
2. Откройте вкладку **Actions** — сборка запустится сама (≈5–8 минут).
3. Когда появится зелёная галочка, откройте запуск → внизу **Artifacts → Volna-apk**.
   Внутри zip лежит `app-release.apk`.

### Вариант 2. Android Studio
(локальная сборка подпишется отладочным ключом и не встанет поверх версии из Releases — сначала удалите её)

1. File → Open → выбрать папку `volna`. Дождаться синхронизации Gradle.
2. Build → Build App Bundle(s) / APK(s) → Build APK(s).
3. APK: `app/build/outputs/apk/debug/app-debug.apk`.

Если Studio предложит обновить Android Gradle Plugin — можно соглашаться.

## Установка
Скиньте APK на телефон, откройте, разрешите «установку из неизвестных источников».
Новые версии ставятся поверх старой — история и лайки сохраняются
(все сборки подписаны одним ключом; в репозитории он лежит только зашифрованным — `app/volna.keystore.enc`, пароль хранится в секрете GitHub `SIGNING_KEY_PASS`).

## Как это работает
- Поиск и потоки — библиотека [NewPipeExtractor](https://github.com/TeamNewPipe/NewPipeExtractor).
  Звук берётся напрямую, поэтому рекламы нет.
- Нажали на песню в поиске → играет она, а за ней бесконечное радио YouTube Music (микс RDAMVM).
- «Для вас» на главной: радио по вашим недавним, любимым и частым исполнителям, отсортированное
  по вашим вкусам. Пропуск в первые 30 секунд считается за «не понравилось»,
  «Не рекомендовать» убирает трек навсегда.
- Shorts, прямые эфиры и ролики короче минуты отфильтровываются везде.
- Прослушанное кэшируется (до 300 МБ), повторы не тратят трафик.

## Если перестало играть / искать
YouTube иногда меняет сайт. Тогда в `app/build.gradle.kts` нужно обновить версию
`NewPipeExtractor` на свежий коммит или тег из
https://github.com/TeamNewPipe/NewPipeExtractor/releases и пересобрать.
